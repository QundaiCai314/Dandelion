# 商业链路诊断报告模板 Output Template

按以下结构输出完整报告（语言跟随用户提问语言）。

## 0. 报告信息 Report Info
- 模式：自检 / 项目检查
- 对象归属：自己的项目 / 他人的项目
- 证据来源：列出实际依据（你的回答、README、官网、定价页、访谈记录、数据等）

## 1. 产品画像 Product Snapshot
一句话总结：目标用户、解决什么痛点、如何收费。

## 2. 逐环节诊断 Per-Stage Diagnosis
每环节输出：
- 判断（1-2 句）
- 依据（注明来源：你的回答 / 公开材料 / 证据不足）
- 分数（0-10）
- 证据不足标记（如有：列出需补充的信息）

## 3. 总分与结论 Verdict
- 各环节分数表（六环 + 平均分）
- 结论：链路打通 / 接近打通 / 未打通，附一句理由
- 他人项目：结论前注明「基于公开证据，不代表产品真实状态」

## 4. 问题清单 Problem List
按优先级排序：断裂环节问题 → 薄弱环节问题。每条包含：环节、问题、影响。

## 5. 修复方案 Fix Plan
对应每个问题给出**完整修改方案**：目标、具体改动、实施步骤、验收标准。AI 只提供方案，由用户自己执行修改。

## 6. 行动清单 Action Plan
Top 3-5 行动：动作、针对环节、预期影响、所需信息或资源。

## 7. 修复进度 Repair Progress
逐项列出：问题/环节、状态（待修复 / 执行中 / 已完成）、产出物（修改方案）、执行人（用户）、复检结果（分数变化）。

## 8. 导出与分享 Export
- 默认生成 Markdown 报告文件：保存到当前工作目录 business-chain-report.md，可直接分享。
- 文件结构 = 本模板全部章节（0-7）。
- 需要 PDF / DOCX 等其他格式时，按用户要求转换输出。
